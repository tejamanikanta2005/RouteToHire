# 🚀 RouteToHire

RouteToHire is an AI-powered career assistant built using **Python, Streamlit, and Google Gemini AI**.

This application helps job seekers analyze resumes, compare them with job descriptions, generate professional cover letters, prepare for interviews, and identify skill gaps with AI.

---

# 🚀 Features

✅ Resume PDF Upload

✅ AI Resume Analysis

✅ ATS-style Job Match Score

✅ Matching & Missing Skills Detection

✅ Resume Improvement Suggestions

✅ Personalized Learning Roadmap

✅ AI Cover Letter Generator

✅ AI Interview Coach

✅ AI Skill Gap Analyzer

✅ Download AI Reports

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/tejamanikanta2005/RouteToHire.git
```

Move into the project folder

```bash
cd RouteToHire
```

Install dependencies

```bash
pip install -r requirements.txt
```

Create a **.env** file

```text
GOOGLE_API_KEY=YOUR_API_KEY
```

Run the project

```bash
streamlit run app.py
```
